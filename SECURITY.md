# Security

Fade custodies liquidity providers' funds. If you find a vulnerability, please do
not open a public issue. Email the maintainers (see the repository's contact in
the GitHub organisation profile) with a description and, if possible, a
reproducing test. You will get an acknowledgement within 72 hours.

Scope: everything under `programs/` and `crates/`. The invariants the program
is expected to uphold are listed in the Technical Specification
(`docs/spec/README.md` §5) and in Spec 08 §12; a violation of any of them is in
scope.
